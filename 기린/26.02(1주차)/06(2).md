# 프로그래머스 - 올바른 괄호

- 문제 링크: [여기](https://school.programmers.co.kr/learn/courses/30/lessons/12909)
- 난이도: lv2

## 🔖 문제 유형

- 스택/큐

## ⏰ 풀이 시간(min)

20 min

## 🤔 스스로 고민한 시간(min)

20 min

## 🧰 접근 방법

- 가장 최근에 열린 괄호부터 닫혀야 한다
- 문자열 순회를 한다
  - 여는 괄호 '(' 를 만나면 스택에 push
  - 닫는 괄호 ')' 를 만났을 떄
    - 스택이 비어있으면 짝이 없는거
    - 비어 있지 않으면 pop (짝 맞추기)
- 문자열 순회가 다 끝났을 때 
  - 스택이 비어 있으면 모두 짝이 맞는거 => true
  - 남아있으면 아직 아닫힌 관호 존재하는거임 => false
