# 프로그래머스 - 완주하지 못한 선수

- 난이도: lv1

## 🔖 문제 유형

- 해시

## ⏰ 풀이 시간(min)

15 min

## 🤔 스스로 고민한 시간(min)

5 min

## 🧰 접근 방법

- 동명 이인이 있으니까 참가자가 몇명인지 count
- name을 key로 count를 value로 하는 map 을 만듦
- 이름 -> 참여자 수 for문으로 세기
- 완주한 사람 빼야하니까 completion에 이름 있는 사람은 count -1
- name이 0 이상이면 완주하지 못한거니까 이름을 return
