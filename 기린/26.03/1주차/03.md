- 해시

## 🤔 스스로 고민한 시간(min)

15 min

## 🧰 접근 방법

### 해시 방식

- 각 전화번호를 map에 저장
- 그리고 각 전화번호에 대해서 for문을 돌면서 prefix를 앞에서부터 하나씪 만들음
  - 만약 그 prefix가 map에 있다면 return false
  - for문을 다 돌았는데도 return이 안되었다면 걍 true를 return

### 정렬 방식 -> 이런 문제는 정렬로 많이 푼다고 함

- 정렬을 하면 앞 부분이 비슷한 전화번호 순으로 비교가 됨
- phon_book[i]이 뒷 부분인 phon_book[i + 1] 의 prefix인지만 확인하면 됨. 아니면 정렬했기 때문에 그 다음 번화의 prefix일 확률이 없음.
- 그래서 for 문 돌면서 phon_book[i + 1] 의 앞부분 phon_book[i]의 길이만큼 잘라서 둘이 같은지 확인.
