# 백준 - 듣보잡

- 문제 링크: [여기](https://www.acmicpc.net/problem/11650)
- 난이도: silver4

## 🔖 문제 유형

- 정렬

## ⏰ 풀이 시간(min)

20 min

## 🤔 스스로 고민한 시간(min)

18 min

## 🧰 접근 방법

- 1 ~ N, N ~ N+M 까지 map에 저장.
- key가 있으면 +1, 없으면(처음 등장) 0
- 듣도 못한 사람, 보도 못한 사람의 명단에는 중복되는 이름이 없다고 했으니까 중복되는 사람이 => 듣보잡
- map에서 value가 1이상인 애들을 듣보잡 배열에 저장
- 출력을 위해 sort 정렬
- 듣보잡 명단의 길이와 명단을 사전 순으로 출력
