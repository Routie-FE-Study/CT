# 백준 - 좌표 정렬하기

- 문제 링크: [여기](https://www.acmicpc.net/problem/11650)
- 난이도: silver5

## 🔖 문제 유형

- 정렬

## ⏰ 풀이 시간(min)

20 min

## 🤔 스스로 고민한 시간(min)

5 min
어떤식으로 죄표를 저장해야 하는지 감이 안잡혔음

## 🧰 접근 방법

- [x, y] 쌍으로 points 배열에 저장
- points 배열을 sort 하는데 "앞의 [x, y] = a"와 "뒤의 [x, y] = b"를 비교
- a[0] 과 b[0] 값이 같으면 => x 좌표 동일, y좌표(a[1] 과 b[1]) 비교,
- 다르면 x 좌표만 비교
- 정렬된 points를 출력
