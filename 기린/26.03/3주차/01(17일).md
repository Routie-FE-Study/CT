- 정렬

## 🧰 접근 방법

- 구해야 하는 값은 h번 이상 인용된 논문이 h편 이상일 때, `h번 이상 인용된 논문의 수`
- 논문의 인용 횟수 배열을 정렬한다.
- for 문을 돌면서
  - 전체 길이(논문의 수) - idx <= value 면, return 그 이상 논문이 몇편인지

🚨 엣지 케이스
마지막에 테스트케이스 한개 통과를 못했는데

- for문을 다 돌아도 값이 안나오는 경우 === 모든 논문의 인용 수가 0일 때
- return 0 처리를 해줘야 함
