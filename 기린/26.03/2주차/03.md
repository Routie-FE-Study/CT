# 프로그래머스 - 가장 큰 수

- 문제 링크: [여기](https://school.programmers.co.kr/learn/courses/30/lessons/42577)
- 난이도: lv2

## 🔖 문제 유형

- 정렬

## ⏰ 풀이 시간(min)

20 min

## 🤔 스스로 고민한 시간(min)

5 min

## 🧰 접근 방법

- 숫자륾 문자열로 변환
- 두수를 이어 붙이서 비교해서 정렬
  - ex) a = "3", b = "30"이면
  - 두 가지 경우 생성: a + b = "330", b + a = "303"
  - 330 > 303
- 이렇게 정렬된 배열을 join 해서 하나의 문자열로 return
- 모든 수가 0일 때는 000이 아니라 0을 return 해야 하기 떄문에 이 경우만 따로 처리
